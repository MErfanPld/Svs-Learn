# 🎓 Svs Learn — Programming & IT Learning Platform

A modern online education platform for selling and managing programming and IT courses.  
**Svs Learn** is designed to provide a professional learning experience for students while giving instructors and administrators powerful tools for content management, course publishing, and user engagement.

This project focuses on scalable architecture, modern UI/UX, and an optimized educational workflow.

---

# 🚀 Overview

**Svs Learn** is an educational platform focused on:

- 💻 Programming Courses
- 🌐 IT & Technology Training
- 🎥 Video-based Learning
- 📚 Course Management
- 👨‍🏫 Instructor Dashboards
- 👨‍🎓 Student Learning Experience

The platform is built to support scalable online education systems with modern web technologies.

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/MErfanPld/Svs-Learn.git
```

## 2. Navigate to the project directory

```bash
cd Svs-Learn
```

---

## 3. Create virtual environment

```bash
python -m venv venv
```

---

## 4. Activate virtual environment

### Linux / macOS

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

## 5. Install dependencies

```bash
pip install -r requirements.txt
```


---

# ▶️ Run the Project

## Django

```bash
python manage.py runserver
```

Server will run on:

```bash
http://127.0.0.1:8000
```
